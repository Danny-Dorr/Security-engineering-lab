# Architecture Design Principles

1. **Segmentation** — avoid a flat network.
2. **Least privilege** — grant only required access.
3. **Default deny** — unauthorized inter-VLAN traffic is blocked.
4. **Centralized enforcement** — routed security policy is enforced by the FortiGate.
5. **Observability** — important activity should generate usable evidence.
6. **Controlled offensive testing** — attack simulations stay within authorized lab scope.
7. **Reproducibility** — document enough to rebuild the environment.
8. **Change control** — make one logical change at a time.
9. **Recovery** — plan for firewall, host, VM, configuration, and security incidents.
10. **Evidence-based documentation** — record objective, action, expected result, actual result, evidence, remediation, and retest.
